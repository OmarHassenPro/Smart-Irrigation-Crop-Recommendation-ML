# Smart-Irrigation-Crop-Recommendation-ML
IoT-based smart agriculture system using machine learning for crop recommendation
###  Dataset

Dataset used: Crop Recommendation Dataset (Kaggle)  
https://www.kaggle.com/datasets/chitrakumari25/smart-agricultural-production-optimizing-engine

## Overview

This project presents an IoT-based smart agriculture system that uses machine learning to recommend the most suitable crop based on soil and environmental conditions.


## Features
Crop prediction using ML models
Custom irrigation score feature engineering
Model comparison:
Logistic Regression
Decision Tree
Random Forest
PCA visualization
Confusion matrix evaluation
Feature importance analysis



## Dataset info
2200 samples
22 crop classes (balanced)
Features:
N, P, K
temperature
humidity
pH
rainfall
irrigation score
